Elegir receta

Nueva receta

Usa el botón "Pedir ideas a Claude" (pestaña Mi semana) para copiar el prompt con el esquema correcto, o pega aquí un JSON con proteina, verdura (array, siempre presente) e hidrato. Si faltan, la app los deduce automáticamente.

Ambos casos: la app no puede estructurar la receta sola (necesita IA) — el botón copia un prompt listo para pegar en un chat con Claude; el PDF vuelca su texto abajo para pegarlo tú mismo en ese chat. Recibes un JSON → lo pegas en la caja de debajo.
